# Frontend

React 19 + TypeScript, scaffolded with Vite. See the
[repository root README](../README.md#frontend-phase-5) for what this app
does, how it talks to the backend, and how to run it.

```bash
npm install
npm run dev     # http://localhost:5173, proxies /api to localhost:8080
npm run build   # type-checks (tsc -b) then builds
npm run lint    # oxlint
```
